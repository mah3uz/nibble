# Assets

Assets are uploaded once and used anywhere. The browser shows folders, search, and what each asset is used by, so
you can tell before deleting whether anything points at it.

## Images

An image can be **cropped** per use and given a **focal point**, so the same image can be a wide banner in one
place and a square card in another without uploading it twice. Sizes are named by the site — `card`, `hero`,
`content` — and Nibble generates each on demand, cached by content, so a changed crop is never a stale URL.

Alt text belongs on the asset, so it travels with the image wherever it is used.

## Files

Documents and other files work the same way, without the image tools. What may be uploaded, and how large, is a
site setting.

## In rich text

An image placed in rich text is a reference to the asset, not a copy: replace the asset and every page using it
follows.
