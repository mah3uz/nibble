# Navigation

A navigation is a tree you arrange by dragging. Each item points at an entry or at a URL you type, and may have
fields of its own if the site defines them.

Pointing an item at an entry rather than a URL means the link follows the entry: if its slug changes, the menu is
still right.

A site may have several — a main menu, a footer, anything the theme asks for. Which ones exist is part of the
site's schema.
